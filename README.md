# Controle de Receitas

Aplicativo simples para controlar receitas retidas e entregues, com cadastro de medicamentos, dosagem com unidade, login por usuário e backup dos dados.

## Acessar o aplicativo

[https://fabio-portfolio-ti.github.io/controle-de-receitas/](https://fabio-portfolio-ti.github.io/controle-de-receitas/)

Basta abrir o link no navegador, no computador ou no celular. Não é preciso instalar nada.

## Usar no computador (Windows)

**Opção 1: pelo link**
1. Abra o link acima no Google Chrome ou no Microsoft Edge.
2. Para ter um atalho: no Chrome, menu de três pontinhos > **Transmitir, salvar e compartilhar** > **Criar atalho**. No Edge, menu > **Aplicativos** > **Instalar este site como um aplicativo**.

**Opção 2: baixar os arquivos**
1. Nesta página do GitHub, clique em **Code** > **Download ZIP**.
2. Extraia a pasta no computador.
3. Dê dois cliques em `index.html` para abrir no navegador.

## Usar no celular (Android)

1. Abra o link acima no **Google Chrome**.
2. Toque nos três pontinhos no canto superior direito.
3. Toque em **Adicionar à tela inicial**.
4. Confirme. O ícone fica na tela do celular, como um aplicativo.

## Importante sobre os dados

- Os dados ficam guardados **somente no aparelho** em que foram digitados. O computador e o celular não sincronizam.
- Para levar os dados de um aparelho para outro: use **Salvar backup** no primeiro e **Importar backup** no segundo.
- Faça backup com frequência. O aplicativo avisa quando passam 30 dias.
- Não limpe os dados de navegação sem antes salvar um backup.
- Nunca envie arquivos de backup para o GitHub, pois contêm dados de pacientes.
